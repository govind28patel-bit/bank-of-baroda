# Redesigning Bank of Baroda Website: Usability Testing

Portfolio case study by **Govind Patel**, UI/UX designer, Pune.

**Live site:** https://govind28patel-bit.github.io/bank-of-baroda/

An animated, interactive case study covering:

- Competitive analysis against SBI, Axis and HDFC
- Usability testing with 3 participants (5 loan tasks), with their answers
- Persona, heuristic evaluation and UX-law audit
- Finding → Change mapping from test results to design decisions
- Information architecture, old vs new comparisons
- Clickable personal-loan and fixed-deposit flows
- Round 2 test plan for the redesigned prototype

Design and prototype: [Figma file](https://www.figma.com/design/cjl2SquZYihXplPixPgAXh/Usability-Testing?node-id=50-636)
